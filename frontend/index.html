🖥 App hosting

Google Cloud Run free tier (2M req/mo), Fly.io or Render. Dockerfile included.

⏰ Scheduler

GitHub Actions cron every 15 min (2,000 free min/mo) calls /api/cron/tick.

⚡ Edge worker

Cloudflare Worker (100k req/day free) — cloudflare/worker.js.

🔄 No-code

Self-hosted n8n workflow JSON included for visual automation.

🔑 APIs

Meta Developer, Google Cloud (YouTube) — free; Meta needs app review for advanced perms.

🗄 Database

SQLite for demo; Turso (9GB free) or Neon Postgres via DATABASE_URL.

🚀 Deploy commands

cd backend && pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000      # local (mock mode)

gcloud run deploy socialauto --source . --region asia-south1 --allow-unauthenticated \
  --set-env-vars MOCK_MODE=false,CRON_SECRET=your_long_secret
# then add GitHub secrets: APP_URL + CRON_SECRET  → posts auto-publish every 15 min
